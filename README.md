# Switzerland & Italy Trip Web

瑞士 × 意大利 2026 旅行的公开手机执行面板。

## 产品定位

- 手机优先，而非旅行博客
- 快速查看当天路线、交通缓冲、天气、预算与拍摄任务
- 支持晴天、雨天、跳伞成功、跳伞取消四种方案切换
- 所有地图入口只使用可公开的地点名称

## 隐私边界

本仓库只存放公开版行程数据。禁止提交二维码、订单号、证件、保险单、银行卡信息或任何可直接使用的票据。

## 开发

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
npm run build
```

## 目录

- `app/`：页面与样式
- `data/`：脱敏后的公开行程数据
- `public/`：公开静态资源
- `.github/workflows/`：持续构建检查
