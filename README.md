# Switzerland & Italy Trip Web

瑞士 × 意大利 2026 旅行的公开手机执行面板。

## 产品定位

- 手机优先，而非旅行博客
- 按日期查看时间轴、交通、地图、预算、票务、补给、行李、穿搭和 Plan B
- Vlog 模块收录正式手册中的背景、口播、旁白、镜头、转场和现场变化话术
- 所有地图入口只使用可公开的地点名称

## 数据版本

- 行程与预算：V1.5 修订版（2026-09-08）
- Vlog：2026 瑞士意大利 Vlog 拍摄与口播手册
- 网站公开数据更新：2026-09-13
- Swiss Travel Pass：4日票，2026-09-27 至 2026-09-30
- 旅行保险：已购、已付；续期及跳伞承保待确认

## 隐私边界

本仓库只存放公开版行程数据。禁止提交二维码、订单号、证件、保险单、银行卡信息、住宿门牌或任何可直接使用的票据。

## 开发

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
npm run build
npm run build:pages
```

## 目录

- `app/`：页面与样式
- `data/`：脱敏后的公开行程数据
- `public/`：公开静态资源
- `.github/workflows/`：持续构建检查
